# NS-UNO
### Neutron Star EoS Inference from an Unconstrained Number of Observations

> **Every neutron star plays its part.**

NS-UNO is a simulation-based inference framework for reconstructing the
neutron-star equation of state (EoS) from observations of an unconstrained
number of neutron stars.

The framework uses conditional normalizing flows to learn the posterior
distribution of the EoS conditioned on neutron-star observables such as
mass, radius, and tidal deformability.
